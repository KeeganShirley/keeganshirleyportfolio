Chat-GP3P0: A Conversational AI Model

A functional AI-powered LLM chatbot that pulls from a custom knowledge base using retrieval-augmented generation. Primed with the full script of Star Wars: A New Hope, it gives thoughtful, in-character answers about the film, its significance, and its cultural impact.

Amazon BedrockAmazon LexAmazon S3Claude by Anthropic
Objectives

Functional Requirements

  • ✓ Provide intelligent, thoughtful responses to all questions about Star Wars: A New Hope
  • ✓ Integrate the chatbot with a comprehensive knowledge base of detailed film information
 

Non-Functional Requirements

  • ✓ Maintain an average response time under 3 seconds per query
  • ✓ Uptime availability of 99.95%
Architecture

Workflow & Draft Architecture

  1. 1 Choose an appropriate foundational model in Amazon Bedrock
  2. 2 Store reference data in an Amazon S3 bucket
  3. 3 Create a knowledge base in Bedrock, add the S3 bucket, and connect the foundational model
  4. 4 Configure the AI chatbot agent using Amazon Lex and add intents
  5. 5 Test and monitor performance
Building It

From foundational model to working chatbot

Selecting a foundational model. Claude by Anthropic was the right fit for this project because of its advanced language understanding and generation — with a serverless deployment type and a 100,000-token context window, it comfortably handles the application's request load.

Creating the S3 bucket. I created a general-purpose bucket with encryption enabled and uploaded the full script of Star Wars: A New Hope as the first data deposit.

STEP 03

Integrating a knowledge base

Back in Bedrock, I created a knowledge base for the foundational model to pull from, chose S3 as the data source, and pointed it at the bucket from the previous step — using the default embedding model and vector store.

STEP 04

Configuring a chatbot with Amazon Lex

I named the bot, created an IAM role granting Lex the minimum permissions needed, and added a hard-coded WelcomeIntent to greet new users. I then added a built-in generative AI intent, QnABotIntent, to parse the knowledge base and generate thoughtful responses to user questions.

STEP 05

Testing for effectiveness

With the chatbot developed, primed with a knowledge base, and connected to a web application, I ran queries to gauge response accuracy and effectiveness. As I added more information to the S3 bucket for context, the responses became noticeably more insightful.

Results

Requirements Evaluation

  • ✓ Intelligent responses — Chat-GP3P0 provides thoughtful, contextually relevant answers using Claude by Anthropic for advanced language understanding.
  • ✓ Knowledge base integration — connected to a comprehensive S3-backed knowledge base via Amazon Bedrock.
  • ✓ Response time — testing samples show a consistent average under 2 seconds, beating the 3-second target.
  • ✓ Uptime — based on AWS service SLAs, the system achieves at least 99.95% monthly uptime.
